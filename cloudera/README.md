# Cloudera Data Engineering & Apache Spark Labs

Welcome! This directory serves as a centralized portfolio of hands-on labs, SQL scripts, and interactive Apache Zeppelin notebooks focused on **Big Data engineering, distributed processing, and query optimization** on **Cloudera Data Platform (CDP)** using **Apache Hive**, **Apache Impala**, and **Apache Spark (PySpark & Scala)**.

---

## Tech Stack & Tools

* **Big Data Ecosystem:** Cloudera Data Platform (CDP), Apache Hadoop (HDFS), Apache YARN
* **SQL & Data Warehousing:** Apache Hive, Apache Impala, Cloudera Hue
* **Distributed Computing:** Apache Spark 3 (PySpark, Scala, Spark SQL, DataFrames, RDDs, Catalyst Optimizer)
* **Interactive Notebooks:** Apache Zeppelin (Livy, Spark, PySpark, Shell & JDBC interpreters)
* **Storage & File Formats:** Apache Parquet, Apache ORC (ACID Transactional), RegexSerDe, Delimited Textfiles, JSON, CSV
