# Google Cloud Platform (GCP) Data Engineering Labs

Welcome! This directory contains hands-on labs, cloud architectures, and data engineering workflows built on **Google Cloud Platform (GCP)**.

---

## Tech Stack & Cloud Services

* **Compute & Infrastructure:** Compute Engine, Google Cloud Marketplace, Infrastructure Manager, Cloud Shell (`gcloud` CLI)
* **Networking:** VPC Networks, External IP Routing, Firewall Rules
* **Application Stacks:** Linux (Ubuntu), Apache HTTP Server, MySQL, PHP
